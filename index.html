The public OSM server allows at most 1 request per second. Checking a place takes 1–2 requests; the browser remembers the results, so they are not requested again.

Log in with a GitHub token

Your decisions are saved to your own file in the repository. This needs a personal access token (you only create it once). You also need write access to the repository (ask its owner to add you as a collaborator).

Option 1 (recommended): fine-grained token

  1. Open: new fine-grained token.
  2. Resource owner: the organization that owns the repository (). Repository access: Only select repositories → this repository.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate token, then paste it here. It starts with github_pat_.

If the organization is not listed as a resource owner, or the token stays “pending”, an organization owner must allow (or approve) fine-grained tokens. Until then, use option 2.

Option 2: classic token
  1. Open: new classic token.
  2. Scope: repo for a private repository, public_repo for a public one. Set an expiration date.
  3. If the organization uses single sign-on (SSO): in the token list, click Configure SSO and authorize the token for the organization.
  4. Paste it here. It starts with ghp_.

A classic token can access all of your repositories, not only this one. Keep it private and give it an expiration date.

The token is stored only in this browser and is sent only to GitHub. On a shared computer, log out when you finish.
